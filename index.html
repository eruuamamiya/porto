Mail Matrix

Generator email untuk Android

Platform
Android
Bahasa
Java
UI
XML native
Riwayat
6 commit

Satu alamat Gmail bisa menjadi ribuan alamat berbeda yang semuanya masuk ke kotak masuk yang sama. Mail Matrix membuatnya dalam sekali ketik, berguna untuk mengelola banyak akun game, media sosial, atau pengujian software.

  • Plus Addressing: menambahkan tag ke alamat, misalnya user+tag@gmail.com, dengan kategori cepat untuk platform populer.
  • Dot Trick: menghasilkan semua variasi titik pada nama pengguna dengan algoritma rekursif berbasis bitmask, sebanyak 2n-1 kombinasi.
  • Anti-crash: nama pengguna dibatasi 15 karakter (maksimal 16.384 kombinasi) supaya aplikasi tidak kehabisan memori di perangkat Android.
  • Pratinjau langsung dan salin sekali ketuk untuk setiap hasil.

    WhatsApp Anonymous Chat Bot

    Bot obrolan anonim acak

    Platform
    WhatsApp
    Runtime
    Node.js 16+
    Library
    @whiskeysockets/baileys
    Riwayat
    22 commit

    Bot yang mempertemukan dua pengguna secara acak untuk mengobrol tanpa membuka identitas, seperti fitur random chat di Telegram. Nomor WhatsApp tiap pengguna disembunyikan dari lawan bicaranya.

    • Antrean pencarian yang mencocokkan dua pengguna dengan cepat.
    • Dukungan media: teks, gambar, video, dan stiker diteruskan antar pengguna.
    • Ringan: cukup untuk berjalan di server mini seperti STB (Set Top Box) berbasis Armbian atau VPS kecil.
    • /start atau /search cari pasangan
    • /next ganti pasangan
    • /stop keluar
